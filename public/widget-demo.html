示範頁 浮動小幫手外掛

右下角那顆 💬 就是掛上去的浮動機器人 — 點開直接和「小幫手」對話，本頁只有下面這一段 script，其他都是普通網頁內容。

<script src="https://你的聊天室網址/widget.js" defer></script>

一般掛法（自動連回 widget.js 的來源站）

<script src="https://classroom-chat-u1td.onrender.com/widget.js" defer></script>

自訂掛法

<script
  src="https://classroom-chat-u1td.onrender.com/widget.js"
  data-nickname="三年二班訪客"
  data-accent="#3b82f6"
  data-position="left"
  defer></script>

或用 window.ChatWidget API 動態控制：

window.ChatWidget.open()   // 打開
window.ChatWidget.close()  // 收起
window.ChatWidget.toggle() // 切換
window.ChatWidget.config({ accent: '#f97316', nickname: '導覽機器人' })

data-* 參數

參數預設說明
data-serverwidget.js 來源站 /wsWebSocket 位址（跨網站放置也可指定）
data-nickname「訪客」預設顯示暱稱（每台瀏覽器自動加穩定編號，如 訪客‑123，多名訪客可同時各開各的私人房）
data-room（空）指定加入的房間 ID；空值會自動開一間私人「小幫手」房
data-accent#06c755主題色
data-image（無，顯示 💬）浮動按鈕用圖片網址（如校徽）；開啟時圖上疊 ✕，標頭頭像也會跟著換
data-positionright右下角或 left 左下角
data-greeting打招呼文案開啟時的第一句
